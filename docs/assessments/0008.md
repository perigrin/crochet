# Assessment: 0008, doc-first is enforced by review

Threshing session over `docs/decisions/0008-doc-first-enforcement.md`, five
rounds, concluded at `b9859ed`. Outcome: **unity**.

Both participants recommend **accept** with nothing outstanding. `enf-cold`
raised seven findings and released seven; `enf-evidence` tested thirty-four
claims, falsified six, and released every one after re-verification. Neither had
seen `0004-architecture-synthesis.md` or the nine-round assessment it came from.

## The three axes

**Codebase.** Every factual claim was re-derived rather than checked. `covers:`
counts, the `rfc-0003` false-positive hazard, 0002's two hostile citations,
`ZHI_ACTOR`'s absence from the live layer, `review.md` containing no
live-document step, `CLAUDE.md`'s import list — all confirmed independently. The
`docs health` claims were rebuilt in four controlled repositories with commit
dates an hour apart and a positive control proving the harness could count.

**Architecture.** Six claims were falsified and each was answered. Two made the
decision's case stronger once corrected.

**Direction.** Doc-first is a rule 0001 wrote and no gate has ever enforced.
Both participants agree the decision closes that, and both agree it does not
climb 0001's ladder — a step in a skill file is rung 3, the same rung as the
prose it replaces. What the decision now claims is narrower and true: the
obligation moves from the author, who is asked to remember it, to a mandatory
gate that performs it.

## What the round found

**`CLAUDE.md` was invisible to its own lens**, reached independently by both
participants from opposite directions — one from the file being unreachable, the
other from the definition excluding its own source. It imports nothing of
itself, carries no `covers:`, and sits outside `docs/`. It is also the one live
document with drift on the record: 0003's Scope of Change documents it asserting
a rule the decision it cited had already replaced. **A lens for doc-first that
could not read `CLAUDE.md` would have missed the only failure of doc-first this
repository has recorded.**

**The live layer does not agree with itself about doc-first.** 0001 says "in one
PR", `development-workflow.md` says "in the same pull request", `CLAUDE.md` says
"in the same commit". The decision's central argument turns on exactly that gap
and had not noticed the contradiction. Under `CLAUDE.md`'s stricter version
`docs health` reports zero always, which is a further silent case and makes the
decision's own argument stronger.

**0001 never asked for a machine check here.** The decision argued against a
demand 0001 does not make, while 0001's actual concession — "a test is
machine-checkable and an architecture statement is not. This buys the
discipline, not the proof" — sat unused in the sentence introducing the ladder.

**The backstop was green for 0002 on the day it lands**, and for the wrong
reason: 0002's only appearances in the live layer are `coding-conventions.md`
faulting it twice. The check cannot tell a claim from a criticism.

**A milestone name satisfied the backstop.** `rfc-0001`, `rfc-0003` and
`rfc-0004` each contain a decision number, and `coding-conventions.md` carries
the string `rfc-0003` today in a sentence about something else.

## The criterion that took four rounds

One acceptance criterion — that doc-first is stated once — was wrong four times,
in four different ways, and every version was caught by a participant rather
than by the drafter.

1. **A negated grep for the wording being removed** passed before any work,
   because `CLAUDE.md` wraps that phrase across a line break and the search
   found nothing.
2. **Asserting the replacement instead** proved the new wording arrived and
   could not tell that the old had left. Both participants found this
   independently.
3. **Demanding `in one PR`** required both live documents to adopt an
   abbreviation that appears nowhere in the live layer, to satisfy a grep — the
   trade the decision had declined one criterion earlier.
4. **Squeezing whitespace in the absence halves but not the presence halves**
   would have fired on the first implementation attempt: the corrected sentence
   is 81 characters against a file wrapping in the high seventies, so the break
   lands inside the asserted phrase and three of four conjuncts go green while
   the one that matters reddens for the wrap.

Two limits remain, named rather than fixed: markdown emphasis inside an asserted
phrase breaks a match the way a backtick does, and a negated literal cannot tell
removal from rewording.

## The defect nobody had looked for

`enf-evidence` verified that each forbidden phrase occurs exactly once in its
file, so both absence halves can actually go green — and observed that a second
occurrence would have made the criterion **permanently red with nothing
explaining why**.

> A criterion that passes before its work and a criterion that can never pass are
> the same defect with the sign flipped, and neither is visible from reading. But
> they are not equally cheap to detect. The vacuous pass announces itself the
> moment you run the criterion — it exits 0 and you know. The unsatisfiable one
> exits non-zero, which is exactly what a correct red looks like on day one, so
> running it tells you nothing.

Ten criteria that passed before their work were found across this series. Nobody
once asked whether a criterion could pass at all. The rule that follows —
**run a criterion against a tree where its work is done** — is now in
`crochet:discernment`.

## Standing aside

`enf-cold` recorded one concern and stood aside: that the backstop's population
overlaps doc-first's without matching it, so the check is stricter than the rule
it backs and the gap's cure is a line in the live layer existing only to satisfy
a check. The decision states this in place rather than resolving it.

## On the participants

Both corrected their own accounts unprompted. `enf-cold` refuted one of its own
frozen first-read impressions after reading `xt/run.sh`'s self-test, and caught
the drafter reporting a fix that had never been made — by reading the file
rather than the message describing it. `enf-evidence` flagged that one of its
probes had run against the worktree rather than a copy, and proved the final
criterion in both directions rather than only re-running the red.

## Outcome

**Unity at `b9859ed`.** Five rounds. The decision remains `proposed`; what
follows is the state write, which `crochet:refinement` records rather than
decides.

Two things came out of the session that belong to the repository rather than to
0008: three verified defects in `git zhi docs health`, filed in

carried a trailing slash — so the tool had never watched any of them. Seven
