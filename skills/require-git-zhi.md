## Dependency: git-zhi

Before proceeding, verify that `git-zhi` is available:

```bash
which git-zhi
```

If `git-zhi` is not found, stop and tell the user:

> This skill requires git-zhi. Run `crochet:install` to set it up, or install manually:
>
> ```bash
> curl -fsSL https://raw.githubusercontent.com/perigrin/git-zhi/pu/install.sh | sh
> ```

Do not proceed until git-zhi is confirmed available.
